# MOEX Bond Screener Bot

Асинхронный Telegram бот для поиска и скрининга облигаций Московской Биржи (MOEX).

## Возможности

- 🔍 **Умный фильтр**: Показывает только надежные облигации (LISTLEVEL=1) с активными торгами
- 📈 **Три стратегии инвестирования**: Топ облигации, консервативная и высокодоходная
- 🚀 **Скорость**: Асинхронная работа через `aiogram` и `aiohttp`
- 📊 **Охват**: Ищет в корпоративных (TQCB) и государственных (TQOB) облигациях
- 🎯 **Гибкая фильтрация**: По рейтингу, доходности, дюрации, типу облигаций и частоте купона

## Использование

1. Отправьте боту команду `/start`
2. Выберите одну из стратегий:
   - **🏆 Топ облигации** - Лучшие по рейтингу и доходности (команда `/top_bonds`)
   - **🛡️ Консервативная** - ОФЗ и квазигосударственные, рейтинг ≥BBB, дюрация ≤4 года (команда `/conservative`)
   - **🚀 Высокодоходная** - Доходность >13%, рейтинг A/BBB, купон ежеквартально (команда `/high_yield`)

### Стратегии фильтрации

#### 🏆 Топ облигации
Базовая стратегия для поиска недооцененных облигаций:
- Уровень листинга: 1 (высший)
- Активный статус торгов
- Сортировка по наивысшему рейтингу и доходности

#### 🛡️ Консервативная стратегия
Для минимизации рисков:
- Тип: ОФЗ или квазигосударственные эмитенты (РЖД, Газпром, Сбербанк и др.)
- Кредитный рейтинг: не ниже BBB-
- Дюрация: до 4 лет (короткая/средняя)
- Сортировка по доходности

#### 🚀 Высокодоходная стратегия
Для агрессивного роста капитала:
- Доходность к погашению: выше 13%
- Кредитный рейтинг: A+, A, A-, BBB+, BBB, BBB-
- Частота выплаты купона: ежеквартальная (4 раза в год)
- Сортировка по доходности
